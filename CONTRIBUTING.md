# Guía de contribución

Gracias por tu interés en mejorar el proyecto Tienda TECSUP.

## 1. Reportar errores

Si encuentras un problema en la página:

1. Ingresa al repositorio en GitHub.
2. Abre la sección Issues.
3. Selecciona New Issue.
4. Escribe un título y explica el error encontrado.
5. Indica los pasos para reproducir el problema.

## 2. Proponer mejoras

Para proponer una mejora:

1. Crea una rama para tu modificación.
2. Realiza los cambios necesarios.
3. Prueba que la página funcione correctamente.
4. Guarda los cambios mediante un commit.
5. Sube la rama a GitHub.
6. Crea un Pull Request explicando la modificación.

## 3. Lista de verificación para Pull Requests

Antes de enviar un Pull Request, comprueba lo siguiente:

- [ ] La modificación está relacionada con un Issue.
- [ ] Los cambios fueron probados.
- [ ] Se modificaron únicamente los archivos necesarios.
- [ ] El commit tiene un mensaje descriptivo.
- [ ] El Pull Request explica los cambios realizados.

## 4. Recomendaciones

- Utilizar nombres descriptivos para las ramas.
- Mantener los cambios pequeños y organizados.
- Revisar el código antes de enviarlo.
- Explicar claramente cada modificación.
